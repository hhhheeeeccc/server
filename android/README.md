# نزّل الفيديو — Android Native

نسخة Android أصلية مبنية بـ Kotlin، بواجهة عربية داكنة باسم «نزّل الفيديو».

## الوظائف

- استقبال الروابط عبر مشاركة Android أو فتح الرابط من تطبيق آخر.
- تنزيل الملفات المباشرة المصرح بها عبر HTTPS إلى مجلد `Downloads` باستخدام `DownloadManager`.
- عرض التنزيلات وحالاتها، مع أدوات لإعادة التسمية أو الإلغاء/الحذف.
- دعم MP4 وM4V وMOV وWEBM وMKV وAVI وMP3 وM4A وAAC وWAV.

## حدود الاستخدام

لا تستخرج هذه النسخة ملفات من صفحات YouTube أو Instagram أو Snapchat أو Telegram أو TikTok، ولا تتجاوز DRM أو تسجيل الدخول أو أي حماية للمنصات. رابط صفحة المشاهدة ليس رابط ملف مباشرًا. نزّل فقط المواد التي تملك حق تنزيلها.

## البناء والتثبيت

افتح مجلد `android/` في Android Studio، نفّذ Gradle Sync، ثم ابنِ `app` بصيغة Debug. يتطلب البناء Android SDK 35 وJDK 17 أو أحدث. APK الـDebug يُوقّع بمفتاح تطوير محلي ولا يصلح كتحديث لتطبيق موقّع بمفتاح آخر.

هذه نسخة مستقلة بمعرّف الحزمة `com.videoload.android`؛ لذلك لا تستبدل التطبيق المرجعي ذي المعرّف المختلف `com.zai.downlite`.
