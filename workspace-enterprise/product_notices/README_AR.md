# تعطيل الاتصال بخدمة إشعارات المنتج

تستدعي تهيئة Enterprise المركزية `product_notices.Disable()` قبل إنشاء مخزن
الإعدادات. تفرض القيم الفعلية التالية باستخدام آلية تجاوز الإعدادات الموجودة
في الكور:

```text
MM_ANNOUNCEMENTSETTINGS_ADMINNOTICESENABLED=false
MM_ANNOUNCEMENTSETTINGS_USERNOTICESENABLED=false
MM_ANNOUNCEMENTSETTINGS_NOTICESURL=
```

هذا يوقف جلب إشعارات المنتج عند بدء التشغيل وجدولتها في الخلفية، ويجعل
واجهة إشعارات المنتج تحصل على قائمة فارغة. يبقى التعطيل نافذًا حتى إذا كان
ملف إعدادات قديم أو متغير بيئة خارجي يفعّل الإشعارات. إعادة تحميل الإعدادات
أو محاولة تفعيلها من لوحة النظام لا يعيدان الاتصال. تظهر الحقول كتجاوزات بيئة
في إعدادات النظام، ولا نغيّر ملف الإعدادات المحفوظ بهذه السياسة.

يعمل التعطيل بوجود الترخيص وبدونه. لا تحتاج هذه السياسة إلى تعديل ملفات
`mattermost/server` أو إلى `-overlay`؛ تدخل في البناء المعتاد مع وسم
`enterprise`. تحتاج النسخة المشغلة إلى إعادة بناء وإعادة تشغيل لتضمينها.

## التحقق

من `mattermost/server`، دون تشغيل خادم أو الاتصال بقاعدة بيانات:

```bash
go test ../../workspace-enterprise/product_notices
```

يغطي الاختبار إعدادات قديمة مفعّلة، وتجاوزات بيئة مفعّلة، ومحاولة إعادة
التفعيل والحفظ وإعادة التحميل، والتأكد من توقف جدولة مهمة الإشعارات.
