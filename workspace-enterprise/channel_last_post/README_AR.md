# معاينة آخر رسالة في القناة

تسجل الحزمة وسيط HTTP من `enterprise/main.go` يضيف `last_post_id` و`last_post`
إلى استجابات القنوات المصرح بها. يتحقق مسار Mattermost الأصلي من الجلسة
والصلاحيات؛ لا تنشئ الحزمة مسارًا جديدًا ولا تعدل `mattermost/server/`.
إذا تجاوز رد القنوات المضغوط 16 MiB، يُمرَّر الرد الأصلي تدريجيًا دون
إضافة المعاينة. وإذا تجاوز الرد بعد فك الضغط 32 MiB، يُمرَّر الرد الأصلي
كما هو. بذلك تبقى استجابة القنوات متاحة دون تخزين رد أو فك ضغط غير محدودين؛
قد لا تظهر المعاينة في الردود الكبيرة جدًا.

تختار المعاينة أحدث رسالة رئيسية غير محذوفة وغير نظامية لكل قناة، وتستبعد ردود المواضيع حتى لو كانت أحدث. يقرأ الاستعلام
المنشور كاملًا من قاعدة الكتابة في لقطة واحدة، ثم تمرره الحزمة إلى
`PreparePostForClient`. بذلك لا يعود نص قديم من نسخة قراءة متأخرة بعد تعديل
الرسالة، ولا تعود الرسالة المحذوفة بدل سابقتها. عند عدم وجود منشور ظاهر
تعود `last_post_id` فارغة و`last_post` بقيمة `null` حتى تمسح الواجهة
المعاينة السابقة. لا تُضاف هذه الحقول دون رخصة Enterprise.

## التحقق والحدود

نجح `go test ./channel_last_post -count=1` لاختبارات ترميز الاستجابة، ونجح
`go test . -run '^TestChannelResponsesIncludeLatestVisibleUserPost$' -count=1`
مع PostgreSQL وكاش محلي. يغطي اختبار API تعديل الرسالة، وحذف رسالة أحدث
والرجوع إلى سابقتها، ثم فراغ المعاينة بعد حذف الأخيرة.
تشمل اختبارات الحزمة حد فك الضغط لكل الترميزات المدعومة، وتمرير الرد الأصلي
مع الحالة والترويسات نفسها عند تجاوز حد التخزين.

تضيف القراءة استعلامًا على قاعدة الكتابة عند جلب القنوات؛ يلزم قياس كلفتها
مع عدد قنوات وحمل إنتاجيين. يجب إعادة بناء خادم Enterprise وتشغيله ونشر
واجهة الويب الجديدة قبل اعتبار سلوك المتصفح المنشور متحققًا. لا يثبت اختبار
API المحلي تزامن واجهة متصفح أو تجربة عدة عقد فعلية. أُعيد بناء
`webapp/channels/dist` في 27 سبتمبر بعد منع حدث رسالة متأخر من إعادة معاينة
معدلة أو محذوفة، وتطابق ملف الدخول الذي يقدمه الموقع مع البناء الجديد؛
يبقى اختبار التفاعل داخل المتصفح مطلوبًا.

## تحسين الأداء — 15 أكتوبر 2026

أصبحت قراءة آخر رسالة تستخدم `LATERAL … LIMIT 1` لكل قناة مع الفهرس الموجود،
بدل ترتيب كامل تاريخ الرسائل المطابقة. جُمعت الأولويات والإقرارات في قراءتين
من قاعدة الكتابة، مع الرجوع إلى تجهيزها الأصلي عند الخطأ. لا يحتاج التعديل
migration. تفاصيل القياسات والاختبارات وحدودها في
[تقرير الأداء](../deployment/performance/README_AR.md).
