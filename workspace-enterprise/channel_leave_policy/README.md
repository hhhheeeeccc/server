# سياسة مغادرة القنوات

تمنع المغادرة الذاتية للقنوات العامة والخاصة إلا لمسؤول النظام `system_admin`
أو مسؤول **الفريق الذي تنتمي إليه القناة**. مسؤول القناة وحده، ومسؤول فريق
آخر، والعضو العادي، والضيف لا يملكون هذه الصلاحية.

## مكان التنفيذ

- `service.go`: فحص جلسة الطلب والصلاحية، وحماية طلب حذف عضوية النفس
  `DELETE /api/v4/channels/{channel_id}/members/{user_id}`، بما فيه `me`.
  يفحص أيضًا أوامر المغادرة المرسلة إلى `POST /api/v4/commands/execute`؛
  يرجع `403` عند رفضها قبل تنفيذ الأمر.
- `commands.go`: تغليف مقدمي الأوامر الموجودين باستخدام
  `app.RegisterCommandProvider`، لحماية `/leave` و`/remove` و`/kick` حتى عند
  استدعائهم من داخل التطبيق. الأمران الأخيران يُفحصان فقط عند استهداف النفس.
  الأسماء العربية `/مغادرة` و`/إزالة` و`/طرد` تستخدم الفحص نفسه.
- التسجيل مركزي في `workspace-enterprise/main.go` بواسطة وصلة Enterprise
  الحالية و`Router.Use`، دون تعديل ملفات `mattermost/server` أو إنشاء إضافة.

يعتمد التحقق على هوية الجلسة الفعلية و`channel.TeamId`؛ لا يعتمد على
`user_id` أو `team_id` المرسلَين داخل طلب تنفيذ الأمر. يقبل عضوية فريق نشطة
بـ`SchemeAdmin` أو الدور `team_admin`، ولا يقبل عضوية محذوفة.

**حسب الطلب، قيد الصلاحية هذا يعمل حتى عند غياب الترخيص**، فلا يؤدي فقدان
الترخيص إلى السماح للعضو العادي بالمغادرة. لا ينشئ أي ترخيص ولا يفعّل ميزات
Enterprise الأخرى دون ترخيص.

عند السماح بالعملية يكمل المسار الأصلي تنفيذها، بما فيه التحقق من صلاحيات
النظام وقيود القناة الافتراضية والمجموعات والتدقيق. إزالة مستخدم آخر تظل
خاضعة للصلاحيات الأصلية. إخفاء محادثة مباشرة أو جماعية من الشريط الجانبي
ليس مغادرة قناة فريق ولا تمنعه هذه السياسة.

## الاختبار والبناء

من مجلد `mattermost/server`:

```bash
go test ../../workspace-enterprise/channel_leave_policy ../../workspace-enterprise/slash_commands
go build -tags 'enterprise sourceavailable' -o bin/mattermost ./cmd/mattermost
```

يحتوي `integration/policy_test.go` اختبارات HTTP حقيقية للعضوية والقنوات
العامة والخاصة، والأوامر، والصلاحيات، مع الترخيص وبدونه. يحتاج PostgreSQL
محليًا معزولًا للاختبار فقط. يتعمد رفض التشغيل دون متغير
`TEST_DATABASE_POSTGRESQL_DSN` يشير إلى Unix socket داخل مجلد مؤقت يبدأ
بـ`/tmp/workspace-channel-leave-`، لأن أدوات اختبار المشروع تنشئ قواعد وتحذفها.

```bash
python3 ../../workspace-enterprise/channel_leave_policy/integration/run.py
```

السكربت يستخدم PostgreSQL 16 من `/usr/lib/postgresql/16/bin`؛ يمكن اختيار
نسخة محلية أخرى عبر `PG_BINDIR`. يبني اختبارًا منفصلًا، وينشئ قاعدة مؤقتة
بـUnix socket دون الاستماع على TCP، ثم يوقفها ويحذف ملفاتها. سجل النتيجة
في `/tmp/workspace-channel-leave-integration.log`.

لا تحتاج الميزة خدمة خارجية جديدة أو migration. يلزم تشغيل البناء الجديد
المتضمن Enterprise لتطبيقها على الخادم الفعلي.

طلبات الأوامر التي يزيد جسمها عن 1 MiB لا ينسخها فحص HTTP؛ يترك تحليلها
للمسار الأصلي، ويظل تغليف مقدم الأمر يمنع تنفيذ المغادرة غير المصرح بها
برسالة خطأ مؤقتة وفق بروتوكول الأوامر الأصلي. كذلك يمنع التغليف الاستدعاءات
الداخلية برسالة مؤقتة، لأن واجهة مقدم الأوامر الأصلية تعيد `CommandResponse`
ولا تتيح إرجاع حالة HTTP مباشرة.
