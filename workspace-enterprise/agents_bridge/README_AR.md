# ربط إضافة Workspace AI

يسجل `main.go` هذا التنفيذ عبر `app.Channels().SetAgentsBridge` عند إنشاء
تطبيق Enterprise. يستخدم الخادم الأساسي عميل `mattermost-plugin-ai` الذي
يرسل الطلبات داخليًا إلى `mattermost-ai`، بينما الإضافة المثبتة تحمل
المعرّف `workspace-ai`. يعيد المحول هنا توجيه وجهة الطلب الداخلي إلى
`workspace-ai` بعد إزالة عميل الربط للجزء الأول من المسار. لا يغير ملفات
`mattermost/server` ولا يعيد تسمية الإضافة.

يفحص `Status` وجود رخصة Enterprise والإضافة النشطة وإصدارها قبل عرض
الوكلاء. تمر طلبات الوكلاء والخدمات والإكمال عبر محول واحد، مع بقاء معرف
المستخدم وأذونات الإضافة الأصلية. إذا لم تتوفر الرخصة أو الإضافة، تبقى
القائمة فارغة وتفشل طلبات الإكمال بدل توجيهها إلى إضافة أخرى.

التحقق المحلي: `go test ./agents_bridge -count=1` و
`go vet ./agents_bridge`. اختبار التوجيه يثبت وصول طلب قائمة الوكلاء وطلب إكمال
الخدمة إلى وجهة `workspace-ai`. يتطلب التحقق النهائي تشغيل خادم مع إضافة
`workspace-ai` نشطة ونموذج مضبوط.
