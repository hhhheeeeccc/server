# اتصالات OAuth الصادرة

تسجل `enterprise/main.go` الواجهة الموجودة في `server/einterfaces`.
تحفظ الاتصالات في مخزن Mattermost الأصلي، وتتطلب راية الرخصة
`OutgoingOAuthConnections`. يقرأ API صلاحيات المسؤول؛ تخفي الاستجابات
`ClientSecret` وكلمة مرور منح `password`، بينما يحتفظ المخزن بالقيم اللازمة
لطلب الرمز. يدعم التنفيذ منح `client_credentials` و`password`، وتدوير السر،
ومطابقة عنوان الجمهور دون قبول مضيف يضيف لاحقة إلى الاسم الأصلي.
ترفض مطابقة الجمهور ذي النجمة مسار هدف يحتوي مقطع `.` أو `..`، حتى لو
كتب مقطع الصعود بشكل URL مشفّر؛ قد يفسره المستقبِل خارج بادئة المسار
المصرح بها. ترفض أيضًا الشرطة المائلة العكسية في المسار. اختُبرت المطابقة
مباشرة وعبر اختيار الاتصال من قاعدة البيانات.

طلب الرمز لا يتبع تحويل `307` أو `308` إلى أصل آخر كي لا يعيد إرسال بيانات
الاعتماد إليه. يميز رفض المزود من فئة `4xx` عن فشل المزود أو الشبكة.
يفحص حالة HTTP قبل قراءة الجسم؛ لذلك يبقى رد `401` رفض اعتماد حتى لو أرسل
المزوّد جسم خطأ أكبر من حد 1 MiB. لا يحتاج المسار إلى جسم رد الرفض.
خطأ النقل الخام قد يضم عنوان نقطة الرمز واستعلامه؛ لذلك لا يُمرر داخل
`AppError` الراجع للعميل. أثبت اختبار تحويل مرفوض أن علامة سرية في الاستعلام
وجسم الطلب لا تظهر في نص الخطأ أو JSON الخاص به.

## التحقق مع مزوّد فعلي

في 17 أكتوبر نجحت اختبارات الحزمة الـ13 مع **Keycloak 26.4.0** وPostgreSQL
معزولين، بما فيها `client_credentials` و`password`. أنشأ الاختبار الاتصال
عبر API ثم نفّذ أمر سلاش من API الأصلي؛ جلب الكور الرمز من خدمة Enterprise
وأرسله إلى مستقبِل محلي لا يقبله حتى تؤكد نقطة introspection في Keycloak
نشاطه وهوية العميل والمستخدم.

نجح تدوير السر لدى Keycloak، ورفض السر القديم، ثم نجاح الرمز والأمر بعد
تحديث الاتصال. شمل الاختبار رفض كلمة مرور خاطئة وحساب عطّله المزوّد،
وحذف الاتصال، ومنع طلب رمز بعد سحب الرخصة، وإخفاء الأسرار من رد API.
اجتاز التنفيذ الحالي هذه الحالات؛ لم يحتج تعديلًا في خدمة OAuth.

نجح أيضًا `GOWORK=off go vet -mod=readonly ./outgoing_oauth_connections`.
بقيت اختبارات محاكاة فشل المزوّد والشبكة وتحويلات HTTP والجسم الكبير ضمن
التشغيل نفسه. [التقرير والدليل](../../workspace-audits/workspace-enterprise-2026-10-22/audit/2026-10-17/outgoing-oauth-keycloak/README_AR.md)
و[طريقة التكرار](../deployment/outgoing_oauth/README_AR.md).

تبقى تجربة مزوّد المؤسسة وبيانات اعتماده وشهادات TLS والشبكة وتعدد العقد
والحمل. لا يختبر هذا المسار دخول Google/Microsoft أو Authorization Code،
ولا يثبت نشر هذه النسخة على الخادم الجاري.
