# الرسائل المختفية من وقت الإرسال

تنفيذ في `/home/marwan/سطح المكتب/workspace`، والخلفية داخل هذا المجلد،
والتسجيل المركزي في `workspace-enterprise/main.go`. الواجهة في
`webapp/channels/src/components/disappearing_messages`.

لتطبيق السلوك نفسه في Android وiOS، راجع [دليل تكامل الموبايل](README_MOBILE_AR.md).

## التشغيل

بعد نشر الخلفية والواجهة المحدثتين مع ترخيص المؤسسة المفعّل:

1. افتح محادثة فردية بين مستخدمين بشريين نشطين.
2. افتح القائمة بجانب اسم الطرف الآخر أعلى المحادثة.
3. اختر **الرسائل المختفية**.
4. اختر **24 ساعة** أو **7 أيام** أو **90 يومًا** ثم **حفظ**.
5. اختر **إيقاف** لإيقاف المؤقت للرسائل الجديدة فقط.

الافتراضي إيقاف. لا تحتاج متغير بيئة خاصًا أو تفعيل Burn-on-Read.
يستطيع الطرف الذي مُنح صلاحية **إدارة الرسائل ذاتية الاختفاء** تعديل الإعداد،
ويظهر إشعار نظام مشترك بالتغيير. الصلاحية غير ممنوحة للأعضاء افتراضيًا؛
يمنحها مدير النظام من **لوحة تحكم النظام ← الصلاحيات ← مخطط صلاحيات
النظام ← جميع الأعضاء ← إدارة الرسائل**. مدير النظام يستطيع تعديل المؤقت أيضًا.
تُطبق الصلاحية على طلب API وأوامر `/اختفاء` و`/disappear`، وليس على
أزرار الواجهة وحدها. سحبها يمنع التغييرات الجديدة ولا يلغي مؤقت المحادثة
أو مواعيد الرسائل المسجلة سابقًا، وتبقى قراءة المؤقت متاحة لطرفي المحادثة.
مدير النظام لا يتجاوز شرط عضوية المحادثة.

يبدأ المؤقت عند حفظ الرسالة باستخدام ساعة PostgreSQL، سواء قُرئت أم لا.
تحفظ كل رسالة موعدها رغم تعديل النص أو تغيير الإعداد. الرسائل السابقة
للتفعيل لا تتغير. الردود داخل سلسلة مؤقتة لا تتجاوز موعد الرسالة الأصلية،
حتى عند إيقاف الوضع لاحقًا. رسائل النظام مستثناة.

النطاق الحالي: المحادثات الفردية فقط؛ القنوات والمحادثات الجماعية والمحادثة
مع النفس والبوتات والمحادثات المشتركة بين الخوادم غير مدعومة.
لا تضيف الميزة وضع «عرض مرة واحدة» أو تشفيرًا من طرف إلى طرف.

## الاستفادة من النظام الحالي

- إنشاء الرسائل والمرفقات العادية وعرضها مباشرةً دون زر كشف المحتوى.
- جلسات الدخول وMFA وعضوية المحادثة ومعالج API الأصلي.
- الحذف الأصلي `App.DeletePost` وإبطال الكاش وحدث `post_deleted` للمزامنة.
- قارئ الملفات الأصلي وصلاحياته، مع حارس للموعد في طبقة Enterprise.
- المودال والقائمة والترجمات وألوان الثيم القائمة في الواجهة.

تُضاف جداول مستقلة داخل مخطط `workspace_message_expiry` ومؤشر للأعمال المعلقة.
يسجل trigger الموعد داخل معاملة حفظ الرسالة نفسها لتجنب حفظ رسالة بلا موعد
عند تعطل العملية. لا يُستبدل Store النظام. تركيب المخطط يحتاج صلاحية DDL؛
فشله يُسجل ولا يُفعّل API. الأمر يبقى معروفًا ويشرح عدم توفر الخدمة.

## حدود الحذف والاحتفاظ

عامل واحد لكل خادم يفحص الطابور المفهرس كل ثانية بحد 25 رسالة في الدفعة.
حجز العمل مؤقت ومشترك بين الخوادم، مع إعادة المحاولة بعد تعطل العامل.
لا يوجد مؤقت أو goroutine لكل رسالة. تقرأ الواجهة الإعداد عند فتح النافذة،
ولا تضيف استطلاعًا مستمرًا.

يستخدم اختفاء النص الحذف المنطقي الأصلي؛ قد يبقى مؤشر «تم حذف الرسالة».
قد يتأخر الحذف بسبب الضغط أو انقطاع الخدمة أو قاعدة البيانات؛ لا يُضمن
تنفيذه في نفس المللي ثانية. تستمر معالجة المواعيد المسجلة إذا انتهى الترخيص،
بينما يحتاج تفعيل الإعداد أو تغييره ترخيصًا.

تُمنع قراءة المرفق ومعاينته ومعلوماته عند الموعد حتى عند تأخر عامل الحذف.
تُمنع الروابط العامة للمرفقات المؤقتة وتُرسل استجاباتها بـ`no-store`.
لا يمكن سحب نسخة سبق تنزيلها أو لقطة شاشة أو محتوى جهاز غير متصل.
لا تحذف الميزة الملفات فعليًا من التخزين أو النسخ الاحتياطية ولا تلغي
الاحتفاظ القانوني؛ الإزالة النهائية مسؤولية آليات النظام وسياسة المؤسسة.
يحتفظ الطابور ببيانات الموعد المكتمل للحماية والتعافي.

## API والأوامر

`GET /api/v4/workspace/channels/{channel_id}/disappearing`

`PUT` إلى المسار نفسه مع:

```json
{"duration_seconds": 86400}
```

القيم المقبولة فقط: `0` و`86400` و`604800` و`7776000`.
الأوامر البديلة داخل المحادثة:

```text
/اختفاء حالة
/اختفاء 24h
/اختفاء 7d
/اختفاء 90d
/اختفاء إيقاف
```

يتوفر أيضًا `/disappear`. صيغة الثواني القديمة مثل `/اختفاء 60` مرفوضة؛
النسخة الحالية تبدأ مدتها من الإرسال.

## التحقق المحلي

- اختبارات Go مع race detector على PostgreSQL مؤقت: ثبات الموعد والرسائل
  السابقة وإيقاف الوضع وصلاحيات العضوية والردود والحجز المتزامن والتعافي.
- تكامل عبر API الأصلي: رسالة عادية ومرفق وجلستان للمستلم وحدث الحذف
  الأصلي وحجب المرفقات ومدخلات JSON غير الصالحة والأوامر العربية.
- اختبارات نافذة الإعدادات والقائمة وعقد عميل GET/PUT وفحص TypeScript.
- متصفح عربي بحساب وهمي وقاعدة مؤقتة: حفظ 24 ساعة وإعادة فتح النافذة
  للتحقق وإرسال رسالة عادية، ثم تقديم موعدها في قاعدة الاختبار فقط؛
  اختفى المحتوى وظهر مؤشر الحذف دون إعادة تحميل الصفحة.

اختبارات التكامل ترفض التشغيل خارج PostgreSQL الاختباري على
`127.0.0.1:55439`. اختبار المستودع يعيد إنشاء مخططات قاعدة الاختبار؛
لا تستخدم بيانات إنتاج. Fixture المتصفح اختيارية عبر
`WORKSPACE_EXPIRY_BROWSER_FIXTURE` وتُغلق بملف لاحقته `.done`.

لم تُنشر التعديلات على الموقع الفعلي ولم تُعد تشغيل خدمته.
