# وظيفة مجلد `legal_hold`

بنية حفظ البايتات المستقلة وغلاف تعديلات مخزن الملفات ومساعد التركيب
قبل بدء التطبيق، وحجز وصف المرفقات وإثباتات SQL الدائمة ومشغلات حراسة
الحذف والتحرير، ومنسق أجيال البايتات ونوايا التعديل والتعافي بقفل أرشيف
مشترك. أضيف سجل قضايا ونطاقات داخلية ببوابات رخصة وصلاحيات، وحفظ
الرسائل والتحريرات والنصوص المؤقتة ووصف الهوية والمرفقات بمشغلات SQL.
توجد اختبارات مسارات الكور وعمليتين على المضيف نفسه. أضيف تصدير داخلي
بلقطة ثابتة دائمة وحزمة متحققة وسجل طلب/محاولات ومفتاح يمنع التكرار،
واستعادة صريحة بعد انقطاع العملية ومساحة محدودة. أضيف تحرير نهائي
بلقطة مثبتة وقراءة تفاصيل القضية وصفحات محدودة، مع حفظ حماية القضايا
المتداخلة والحجوزات المستقلة؛ لا API أو صفحة تنزيل أو تسجيل إنتاجي
أو إدارة كاملة أو تعديل نطاق بعد. تحفظ الترقية الحجوزات القديمة
بوصفها مستقلة مجهولة المصدر؛ لا يرفع التحرير حمايتها الفيزيائية تلقائيًا.
