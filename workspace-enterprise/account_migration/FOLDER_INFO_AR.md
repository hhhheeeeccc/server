# وظيفة مجلد `account_migration`

ترحيل حسابات طرق المصادقة إلى LDAP أو SAML، بما فيه خريطة معرّف SAML الخارجي والفحص الجاف وإلغاء الجلسات.

للتفاصيل: [README_AR.md](README_AR.md).

ملفات بارزة: `README_AR.md`، `api.go`، `doc.go`، `service.go`، `service_integration_test.go`، `session_cleanup.go`.

هذا الوصف يحدد دور المجلد؛ حالة اكتمال الميزة وحدود اختبارها موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).
