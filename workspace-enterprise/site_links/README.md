# إعدادات Workspace عند التوزيع

لا توجد حاليًا صفحات عامة للمساعدة أو الشروط أو الخصوصية أو التعريف، ولا روابط
تنزيل خاصة بـ Workspace. تُترك حقولها فارغة، ويُخفى الإبلاغ عن مشكلة، وتُعطّل
إشعارات أخبار المنتج. لا نستبدل أسماء النطاقات بعناوين وهمية.

## توليد ملف الحزمة

من `~/المستندات/mattermost/server`:

```bash
go run ../../workspace-enterprise/cmd/workspace-config -output ../../workspace-enterprise/dist/workspace/config/config.json
```

يوضع الملف الناتج في `config/config.json` داخل نسخة التوزيع بجانب `bin` و`client`.
شغّل من جذر النسخة:

```bash
./bin/mattermost -c ./config/config.json
```

المولّد يبدأ من قيم الكور الافتراضية ولا يقرأ إعدادات جهاز المطور؛ لا ينسخ
اتصالات قاعدة بياناته أو مفاتيح Nova أو إعدادات إضافاته. يلزم تجهيز اتصال قاعدة
البيانات والخدمات لكل جهة كالمعتاد. يرفض المولّد استبدال ملف موجود، فلا تستخدمه
لتحديث إعدادات جهة سبق تشغيلها.

الإضافات الافتراضية تكون معطّلة في الملف الجديد، وكذلك التثبيت التلقائي
للإضافات المرفقة بالحزمة. تبقى مفاتيح Calls وNPS وPlaybooks وAI مع `Enable: false`
لأن الكور يعيد إنشاءها عند حذفها. راجع `../plugin_ids/README.md` للتفاصيل.

الأمر `go build` يبني الخادم فقط ولا ينقل ملف الإعدادات. كذلك `make package`
في الكور يولّد إعدادات Mattermost الخاصة به؛ عند استخدامه، استبدل ملف الإعدادات
في مجلد التجهيز بملف Workspace هذا قبل ضغط الحزمة. لا توزّع `server/config/config.json`
الخاص بجهازك.

## تطبيق الروابط وقت التشغيل

`site_links.Register` يستبدل فقط روابط Mattermost الافتراضية في نسخة Enterprise
المرخّصة. تبقى روابط الصفحات الحقيقية التي خصّصها المسؤول كما هي.

يُفرض تعطيل إشعارات المنتج قبل تحميل إعدادات الخادم أيضًا من حزمة
`../product_notices`، حتى مع إعدادات قديمة تفعّلها وبدون ترخيص. يظل رابط
الإشعارات الفعلي فارغًا؛ راجع `../product_notices/README_AR.md`.

قيد الكور: `SupportSettings.SetDefaults` يعيد رابط شروط Mattermost عندما تكون
قيمة `TermsOfServiceLink` فارغة. لذلك يعيد `site_links` إفراغه وقت التسجيل بعد
تحميل الترخيص. ملف التوزيع وحده لا يضمن اختفاء رابط الشروط قبل تحميل الترخيص،
ولم نزل شرط الترخيص أو نعدّل الكور لحل ذلك. هذه القيم ليست بديلًا عن إعداد
صفحات شروط وخصوصية حقيقية عند تجهيزها.

لم تُغيّر نقاط خدمات Push وMarketplace وCloud؛ عناوينها تحتاج خدمات بديلة حقيقية.

## التحقق

من `mattermost/server`:

```bash
go test ../../workspace-enterprise/site_links ../../workspace-enterprise/cmd/workspace-config
```
