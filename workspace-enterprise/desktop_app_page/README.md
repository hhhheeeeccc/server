# صفحة تحديث تطبيق تعاون

تعرض هذه الحزمة صفحة عربية RTL لتطبيق سطح المكتب الأقدم من `MinimumDesktopAppVersion`، باستخدام شعار تعاون وخط الواجهة ونفس تخطيط صفحة تسجيل الدخول، مع صورة الواجهة في اللوحة الخضراء. تعمل فقط عند وجود رخصة Enterprise.

يُستخدم `NativeAppSettings.AppDownloadLink` إذا كان رابطًا مخصصًا. إن بقي على رابط Mattermost الافتراضي، تعرض الصفحة رابطَي حزم تعاون المنشورتين لنظامَي Linux وWindows من إصدار 7.0.0. عند نشر إصدار أحدث أو رفع الحد الأدنى المطلوب، حدّث الرابطين في `service.go` بعد التحقق من نشر الحزم، أو اضبط رابط تنزيل مخصصًا في إعدادات التطبيق. أعد بناء الخادم وتشغيله لتظهر التغييرات.
