# روابط واجهات الإضافات

تسجّل هذه الحزمة مسار `GET /api/v4/plugins/webapp` من Enterprise قبل مسار
المضيف، وتعيد روابط الحزم تحت `/static/plugins/` بما يطابق مسار تقديم ملفات
الإضافات. تُبقي بيانات الخادم ومخطط الإعدادات خارج الاستجابة، ولا تغيّر حالة
أي إضافة أو ملفات مصدر Mattermost.

يُفعّل المسار عند وجود ترخيص محمّل فقط؛ عند غيابه يستجيب مسار المضيف الأصلي.
التسجيل المركزي في `main.go`. للبناء والتشغيل استخدم `make run-server` من
مجلد `workspace-enterprise`.

```bash
GOWORK=off go test ./plugin_assets
```
