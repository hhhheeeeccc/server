# وظيفة مجلد `brand`

تقديم صورة العلامة التجارية الافتراضية أو المرفوعة عبر مسار Enterprise.
إذا لم توجد رخصة، يعيد المسار `404` حتى عند بقاء صورة مرفوعة على التخزين.
مع الرخصة يخدم الصورة المرفوعة، ويعرض صورة PNG الافتراضية عند فشل قراءتها.
يمكن لصفحة الدخول طلب الصورة دون جلسة، كما في مسار Mattermost الأصلي.

اختبار API في `service_test.go` أثبت `404` بلا رخصة، وعرض الصورة الافتراضية
دون جلسة مع الرخصة، وعرض صورة PNG مرفوعة، ثم إغلاق الوصول بعد سحب الرخصة.
لا تحتاج التجربة خدمة خارجية؛ يلزم اختبار التخزين المشترك الحقيقي مع عقدتين
وانقطاعه، إذ إن الصورة الافتراضية قد تخفي خطأ قراءة صورة مرفوعة.

حالة بقية الميزات موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).
