# وظيفة مجلد `channel_management`

عمليات إدارة القنوات الإضافية: إعادة تسمية جماعية للقنوات العامة ذات الاسم
نفسه عبر الفرق، واقتراح الأسماء، وعدّ القنوات حسب الاسم. تتطلب رخصة محملة
وصلاحيات قراءة أو كتابة إدارة القنوات في لوحة النظام حسب العملية.
يحد مسار إعادة التسمية جسم الطلب بـ4 KiB، ويرفض الحقول غير المعروفة
وJSON اللاحق؛ يعيد `413` عند تجاوز الحد حتى لو جاءت الزيادة بعد JSON صحيح.

اختبار API في `service_test.go` ينشئ قناتين بالاسم نفسه في فريقين، ويتحقق
من منع القراءة والكتابة بلا رخصة، ومنع المستخدم بلا صلاحية، ثم ظهور العدد
`2` وتحديث اسم العرض للقناتين وصفوف `publicchannels` ونتائج الاقتراح.
في 1 أكتوبر 2026، اختُبر رفض الحقل غير المعروف وJSON اللاحق والجسم الكبير
مع بقاء اسم القناة القديم. نجح `go test ./channel_management -count=1`
و`go vet ./channel_management`.
لا تحتاج التجربة خدمة خارجية؛ يلزم قياس الأداء على عدد كبير من القنوات
وتجربة عقدتين ونسخة قراءة متأخرة قبل اعتماد زمن تحديث الاقتراح في الإنتاج.

حالة بقية الميزات موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).
