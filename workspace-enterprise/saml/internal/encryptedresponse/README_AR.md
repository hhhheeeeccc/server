# معالجة استجابات SAML المشفّرة

هذه حزمة داخلية تستخدمها خدمة `saml` عندما يُفعّل تشفير التأكيدات.
تُبقي نوع `AssertionInfo` الأصلي وواجهة الكور كما هما، وتعيد استخدام
`SAMLServiceProvider.Validate` و`VerifyAssertionConditions` الأصليتين.
لا تحتاج استبدال وحدة Go أو تعديل مخزن الوحدات أو مصدر السيرفر أو سكربت البناء.

## سبب وجودها

اختبار Keycloak 26.4.0 الفعلي في 17 أكتوبر كشف رفض `gosaml2 v0.10.0`
لمعرّف SHA‑256 القياسي `http://www.w3.org/2001/04/xmlenc#sha256`.
المكتبة تتوقع معرّفًا مختلفًا، وتستخدم تجزئة واحدة لكل من OAEP وMGF.
معيار XML Encryption يحدد MGF1‑SHA1 افتراضيًا، حتى عندما يكون
`DigestMethod` هو SHA‑256؛ وقد يحدد المزوّد MGF آخر صراحةً في XML Encryption 1.1.
تغيير إعداد المزوّد إلى خوارزمية أخرى لا يصلح هذا النقص في التكامل.

## أصل الكود والتغييرات

- `decode.go` و`retrieve.go` مشتقان من `github.com/mattermost/gosaml2 v0.10.0`.
  يحفظ `UPSTREAM.json` رقم الالتزام وبصمات ملفات المصدر، ويحفظ `LICENSE`
  ترخيص Apache 2.0 وإشعارات المصدر.
- أُبقي تحليل XML وفحص round-trip وسياق مساحات الأسماء وفحص توقيع
  الاستجابة **قبل** فك التشفير وفحص توقيع التأكيد **بعده**.
- لا يعاد كتابة XML الموقّع لتبديل أسماء الخوارزميات؛ المعالجة تقرأ
  المعلمات الأصلية بعد التحقق من توقيع الاستجابة عند وجوده.
- استُبدل فك RSA‑OAEP بدعم معرّفات SHA‑1/256/384/512 القياسية، وMGF
  المستقل، و`OAEPparams`. بقيت أسماء SHA القديمة للمكتبة متوافقة.
- RSA‑OAEP في XML Encryption 1.0 يثبت MGF1‑SHA1. في XML Encryption 1.1
  يُقرأ MGF الصريح أو يستخدم SHA‑1 الافتراضي؛ المعلمات غير المدعومة مرفوضة.
- يدعم المسار AES‑GCM وAES‑CBC، ويتحقق من حجم المفتاح والبيانات والحشو
  قبل التقطيع. بقي مسار RSA‑v1.5 القديم عبر المكتبة الأصلية للتوافق.
- أُغلق قارئ DEFLATE بعد القراءة، وصُحح إرجاع خطأ تحليل التأكيد المفكوك.
- لا يسمح مدخل الحزمة بتجاوز توقيع SAML؛ ما زالت أخطاء الدخول عامة للمستخدم.

## التحقق والصيانة

تختبر `crypto_test.go` OAEP/TLS key handling باستخدام مفاتيح مؤقتة
وتشفير Go القياسي، بما فيه التجزئتان المختلفتان والمعلمات المرفوضة.
تغطي اختبارات الحزمة الأم مسار HTTP والحسابات والترخيص ومنع إعادة الاستخدام.
ويختبر `TestKeycloakSAML` تأكيدات ينتجها مزوّد هوية فعلي.

عند تحديث `gosaml2`، قارن ملفات المصدر المسجلة في `UPSTREAM.json` بالتحديث،
خصوصًا فحوص XML والتوقيعات. إذا أصلحت المكتبة معرّفات التشفير وMGF، يمكن إزالة
المعالجة المعزولة بعد نجاح الاختبارات نفسها مع المزوّد الحقيقي.
