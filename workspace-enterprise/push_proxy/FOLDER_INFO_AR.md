# وظيفة مجلد `push_proxy`

بوابة HTTP لطلبات Push وACK مع مخزن رموز مشفر في PostgreSQL. تصدر واجهة
Enterprise الرمز من المخزن نفسه، وينشئ العامل الرمز الأول عند الحاجة.
يفحص المجدول المهام المعلقة ويمنع إنشاء مهمة ثانية أثناء تنفيذ الأولى.
يحترم العامل طلب الإيقاف حتى إذا وصل قبل بدء goroutine، ويمكن تشغيله مجددًا.
يبقى نشر البوابة أمام وكيل Push وتجربة الهاتف الفعلي مطلوبين.

للتفاصيل: [CONTRACT_AR.md](CONTRACT_AR.md).

ملفات بارزة: `gateway.go`، `token_store.go`، `service.go`،
`worker.go`، `scheduler.go`، `CONTRACT_AR.md`.

هذا الوصف يحدد دور المجلد؛ حالة اكتمال الميزة وحدود اختبارها موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).
