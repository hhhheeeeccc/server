# وظيفة مجلد `bulk_reactions`

إرجاع تفاعلات عدة منشورات في طلب واحد مع التحقق من صلاحية قراءة كل منشور.

ملفات بارزة: `service.go`، `service_test.go`.

هذا الوصف يحدد دور المجلد؛ حالة اكتمال الميزة وحدود اختبارها موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).

في 1 أكتوبر صار مسار التفاعلات المجمعة يقيّد جسم الطلب إلى 32 KiB، ويرفض
`null` والبيانات اللاحقة بعد JSON وأكثر من 500 معرّف قبل إزالة المكرر.
يعيد `413` للطلب الضخم و`400` للقائمة غير الصالحة؛ تبقى القائمة الصحيحة عند
الحد مقبولة. نجح اختبار API للحالات المذكورة و`go test ./bulk_reactions -count=1`
و`go vet ./bulk_reactions`. لم يُقَس بعد حمل آلاف العملاء المتزامنين.
