# وظيفة مجلد `access_control`

محرك التحكم بالوصول المبني على السمات (ABAC): تقييم القواعد، ترتيب الأولويات، إخفاء البيانات، وربط سمات المستخدم والقناة بخدمة الوصول المسجلة.

ملفات بارزة: `attribute_controls.go`، `engine.go`، `engine_test.go`، `evaluation.go`، `masking.go`، `native_attributes.go`، `rank.go`، `service.go`، `simulation_sessions.go`.

هذا الوصف يحدد دور المجلد؛ حالة اكتمال الميزة وحدود اختبارها موثقة في [خطة النواقص](../docs/REMAINING_FEATURES_AR.md).

## محاكاة المستخدم والجلسة

تستخدم المحاكاة جلسات المستخدم المستهدف الحديثة وتعرض نتائج الأجهزة منفصلة،
مع حصر قراءة بيانات الأجهزة بصاحب صلاحية إدارة النظام. القيم التجريبية لا تُكتب
إلى الجلسات الفعلية. يعرض محرر الواجهة لقطة الجلسة المستعملة ويرسل التغييرات
الصريحة وحدها. راجع [الاختبارات وحدود مرشح الكور عند غياب البيانات](../../workspace-audits/workspace-enterprise-2026-10-22/audit/2026-10-17/simulation-user-sessions/README_AR.md).
