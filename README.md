# محمّل الفيديوهات

تطبيق أندرويد عربي بالكامل (RTL) لتنزيل الفيديوهات من يوتيوب وإنستغرام مباشرة إلى مجلد التنزيلات في الهاتف — **بدون أي تسجيل دخول مطلقًا**.

## المزايا

- **بدون تسجيل دخول**: لا يوجد في التطبيق أي شاشة أو طلب لتسجيل الدخول إلى إنستغرام أو يوتيوب، ولا يجمع أي بيانات.
- **مشاركة مباشرة**: شارك الرابط من تطبيق يوتيوب أو إنستغرام (زر المشاركة ← «محمّل الفيديوهات») واختر الصيغة مباشرة.
- **صيغ متعددة**: فيديو MP4 بأفضل جودة، MP4 بدقة 720p، أو صوت MP3 فقط.
- **محرك حديث**: يعمل على yt-dlp مجمَّعًا لأندرويد عبر مكتبة youtubedl-android (v0.18.1) مع FFmpeg.
- **إنستغرام بدون حساب**: ثلاث استراتيجيات متتالية لاستخراج المنشورات العامة (`graphqlPost` → `fromXdt` → `viaEmbed`).
- **تنزيل موثوق**: خدمة في المقدمة (Foreground Service) مع إشعار تقدم، وكل خطأ يظهر بنص عربي واضح — لا فشل صامت.
- **حفظ منظم**: الملفات تُحفظ في `Downloads/محمّل الفيديوهات/`.

## حدود واضحة (بدون وعود زائفة)

- أندرويد يمنع أي تطبيق من قراءة جلسة تطبيق إنستغرام المثبَّت على الهاتف (عزل النظام). لذلك **المحتوى العام** يُنزَّل بدون أي حساب، بينما **المحتوى الخاص / الستوري** لا يمكن الوصول إليه، ويعرض التطبيق رسالة عربية توضح ذلك.
- اسم التطبيق ومجلد التنزيلات: «محمّل الفيديوهات».

## بناء APK عبر GitHub Actions (بدون حاسوب)

1. بعد رفع الكود إلى هذا المستودع، افتح تبويب **Actions**.
2. اختر سير العمل **بناء APK** ثم **Run workflow** (أو سيعمل تلقائيًا مع كل دفع إلى `main`).
3. عند انتهاء البناء، نزّل ملف المخرجات (artifact) باسم «محمّل-الفيديوهات-APK» — يحتوي ملفي APK (نسخة عادية ونسخة release موقَّعة بمفتاح debug).
4. انقل ملف APK إلى الهاتف وثبّته (اسمح بتثبيت التطبيقات من مصادر غير معروفة في إعدادات الهاتف).

## البناء محليًا

```bash
./gradlew assembleDebug
# الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
```

المتطلبات: JDK 17، Android SDK 34.

## بنية المشروع

```
app/src/main/java/com/muhammil/videos/
├── App.kt                    # تهيئة التطبيق
├── Engine.kt                 # حالة محرك yt-dlp (تهيئة خلفية + إعادة محاولة + لا فشل صامت)
├── MainActivity.kt           # الواجهة الرئيسية (لصق رابط + اختيار صيغة)
├── ShareReceiverActivity.kt  # استقبال الروابط المشارَكة مباشرة
├── InstagramExtractor.kt     # استخراج إنستغرام بدون تسجيل دخول (3 استراتيجيات)
└── DownloadService.kt        # خدمة التنزيل + الإشعارات + الحفظ في Downloads
```

## إشعار قانوني

هذا التطبيق مخصص لتنزيل المحتوى العام لأغراض شخصية. استخدامه قد يخالف شروط خدمة المنصات في بعض الحالات، والمستخدم يتحمل مسؤولية استخدامه. التطبيق غير منشور على متجر Google Play ويوزَّع عن طريق التثبيت المباشر (sideload) فقط.
