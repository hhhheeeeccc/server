# نزّل الفيديو — Nazzil Video

تطبيق أندرويد لتحميل الفيديوهات والصور من إنستغرام والمواقع الأخرى، بواجهة عربية كاملة.

هذا المستودع يُستخدم **قناة تحديث فقط**:

- ملف `VERSION` يحدّد أحدث إصدار (الاسم / الكود / رابط APK المباشر).
- التطبيق يفحص هذا الملف تلقائيًا كل 6 ساعات، ومن الإعدادات زر «البحث عن تحديث».
- ملفات APK تنشر في صفحة [Releases](https://github.com/hhhheeeeccc/server/releases).
